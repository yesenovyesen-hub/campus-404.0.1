# Campus 404

MVP-сервис бюро находок на чистом HTML, CSS и JavaScript ES modules с Vercel serverless endpoint для AI-описаний. Состояние профиля, объявлений, чатов, оценок и активности хранится в `localStorage` браузера. Истории чатов старого MVP автоматически мигрируют в хранилище приложения.

## Локальный запуск

Для статических экранов из корня проекта запустите один из вариантов:

```sh
npx serve .
```

или

```sh
python -m http.server 8000
```

При запуске через Python откройте `http://localhost:8000`.

AI endpoint выполняется как Vercel Function в `api/persona-description.js`; простой статический HTTP-сервер не запускает serverless functions, поэтому AI-кнопка на таком сервере покажет обычное описание карточки как fallback. Для полной локальной проверки используйте Vercel CLI (`vercel dev`) и задайте переменные из `.env.example` в локальном `.env.local`. Файл с секретами исключён из Git.

В Vercel Project Settings → Environment Variables настройте серверные переменные `AI_API_KEY`, `AI_API_URL` (полный HTTPS URL OpenAI-совместимого chat-completions endpoint) и `AI_MODEL`. Не используйте префикс `VITE_`, `NEXT_PUBLIC_` или другие frontend-переменные для ключа. AI API вызывается только серверной функцией; ключ никогда не отправляется браузеру и не сохраняется в `localStorage`.

## Демо

Данные существуют только в текущем браузере; очистка данных сайта удалит их. Рейтинги и диалоги являются демонстрационными и не синхронизируются между посетителями. AI-описание генерируется только по нажатию на бейдж; при ошибке API карточка остаётся доступной и показывает обычное описание.

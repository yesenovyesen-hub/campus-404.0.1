# Campus 404

Статический MVP-сервис бюро находок на чистом HTML, CSS и JavaScript ES modules. Состояние профиля, объявлений, чатов, оценок и активности хранится в `localStorage` браузера. Истории чатов старого MVP автоматически мигрируют в хранилище приложения.

## Локальный запуск

Из корня проекта запустите один из вариантов:

```sh
npx serve .
```

или

```sh
python -m http.server 8000
```

При запуске через Python откройте `http://localhost:8000`.

## Тесты

```sh
node --test
```

## Демо

Данные существуют только в текущем браузере; очистка данных сайта удалит их. Рейтинги и диалоги являются демонстрационными и не синхронизируются между посетителями.
